### What I actually do

Most "AI products" stop at the demo. I build the part after — the queue that retries when the API rate-limits, the database that holds 10,000 posts, the pipeline that regenerates a broken render at 2am without anyone watching.

Three layers:

- **Agent systems** — multi-step tool-calling agents, MCP servers, RAG pipelines, human-in-the-loop workflows
- **Product surfaces** — Next.js dashboards, node-canvas editors, mobile-first UIs people actually want to open
- **Media automation** — FFmpeg render farms, GenAI video pipelines, multi-platform publishing engines
